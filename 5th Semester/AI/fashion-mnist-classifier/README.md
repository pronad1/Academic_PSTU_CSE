# Fashion MNIST Classifier

A web-based application for classifying clothing items from the Fashion MNIST dataset using Convolutional Neural Networks (CNN).

## Features

- 🎯 Accurate clothing item classification
- 🖼️ Upload your own images
- 🎲 Test with random samples from dataset
- 📊 Visual probability distribution
- 🎨 Beautiful web interface
- ⚡ Real-time predictions
