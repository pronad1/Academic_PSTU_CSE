Model: node i always steers directly toward the current position of node i+1 at its own fixed speed (pure pursuit, as in the book's A→B→C→D chase). The final node in each chain has no target and instead sweeps a zigzag heading. All nodes reflect off the window's edges so nobody leaves the field. A collision only deactivates that one chase link — it never stops the simulation. Every other active link keeps moving and can still collide later, and the run always continues until the window's full time has elapsed. The total collision count shown is the count after the complete run, not a running partial count that might still change. Step size (Δt) is fixed within a window for the duration of its run.
