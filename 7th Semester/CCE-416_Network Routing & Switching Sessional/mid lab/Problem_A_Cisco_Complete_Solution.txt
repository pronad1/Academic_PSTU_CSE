TASK 2 - DEVICE SELECTION AND CABLING
====================================
- Use required custom-made 2621XM branch routers.
- Add required serial and FastEthernet modules/interfaces.

TASK 4 - STATIC AND DEFAULT ROUTING
===================================

R1: 4 static routes to branch LAN blocks and one default route to ISP.
Adjust serial interface numbers to actual ports:

enable
configure terminal
ip route 10.1.0.0 255.255.192.0 serial 0/0
ip route 10.1.64.0 255.255.192.0 serial 0/1
ip route 10.1.128.0 255.255.192.0 serial 0/2
ip route 10.1.192.0 255.255.192.0 serial 0/3
ip route 0.0.0.0 0.0.0.0 serial 1/0
end
copy running-config startup-config

ISP routes:
ip route 10.0.1.0 255.255.255.240 serial 0/0
ip route 10.1.0.0 255.255.0.0 serial 0/0

Each branch router default route:
ip route 0.0.0.0 0.0.0.0 <serial-interface-to-R1>


TASK 5 - RIP V1
===============

On each branch router:
router rip
 version 1
 network 10.0.0.0
 network 10.1.0.0
exit

Verify:
show ip protocols
show ip route
show ip route rip

Route symbols:
C = directly connected
R = learned through RIP
S = static
S* = static default route

TROUBLESHOOTING
===============

1. Interface down:
   configure terminal
   interface <correct-interface>
   no shutdown

2. Check interfaces:
   show ip interface brief

3. Serial/DCE:
   show controllers serial
   Set clock rate 64000 on DCE end only.

4. PC cannot ping its gateway:
   Check PC IP, subnet mask, gateway, cable, switch, and router LAN interface.

5. PC can ping gateway but not server:
   Check branch default route, R1 static/default routes, and ISP static routes.

6. DNS fails:
   Check DNS service is On, record is pstu.ac.bd -> 209.165.200.226, and PC DNS is 209.165.200.226.

7. HTTP fails:
   Check HTTP service is On and server IP/gateway are correct.

8. First ping may fail due to ARP. Repeat it.
