## 📖 About

This repository contains coursework, lab assignments, projects, and study materials accumulated throughout a full B.Sc. Engineering programme in **Computer Science and Engineering (CSE)** at **Patuakhali Science & Technology University (PSTU)**, Bangladesh.

It spans **6 semesters**, covering 20+ courses, 100+ lab solutions, and multiple full-scale projects across domains including:
- Data Structures & Algorithms
- Object-Oriented Programming
- Databases & Web Development
- Artificial Intelligence & Machine Learning
- Networking & Socket Programming
- Assembly Language & Microprocessors
- Operating Systems & Simulation

## 🚀 Notable Projects

### 1. 📱 Cross-Platform Donation / Job App (Flutter + Firebase)
> `5th Semester/software/`

A full-featured mobile application built with Flutter for Android, iOS, Web, and Desktop.

- **Authentication** via Firebase Auth
- **Real-time database** with Firestore
- **Chatbot** integration
- **Cross-platform:** Android · iOS · Web · Windows · Linux · macOS
- See: [`5th Semester/software/README.md`](5th%20Semester/software/README.md)

---

### 2. 🌐 Job Portal Website (PHP)
> `first/`

A full-stack web application for job seekers and companies.

- **Backend:** PHP with MySQL
- **Frontend:** HTML, CSS, JavaScript (TinyMCE rich text editor)
- **Features:** Job posting, candidate profiles, company profiles, search, pagination
- See: [`first/readme.md`](first/readme.md)

---

### 3. 🤖 Fashion-MNIST Deep Learning Classifier
> `5th Semester/AI/fashion-mnist-classifier/`

- **Framework:** Keras / TensorFlow
- **Variants:** 10 trained model configurations with hyperparameter tuning
- **Models stored as:** `.h5` weight files

### 4. 🔌 Socket Programming Suite
